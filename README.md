# 遇见

「遇见」是一个面向校园场景的 AI 兴趣社交与搭子小程序 Demo。

当前演示版包含 AI 兴趣画像、自然语言活动创建、智能搜索、搭子匹配解释和聊天回复建议。AI 能力统一通过 `utils/ai.js` 暴露，页面不直接依赖模型服务，后续可替换为 CloudBase 云函数。

陌生人社交安全能力包含活动与用户举报、用户拉黑，以及拉黑后从推荐、活动和消息列表中隐藏。

## 运行方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前文件夹 `E:\遇见-社交平台`。
4. AppID 使用测试号或开发者工具的游客模式。
5. 点击编译即可体验。

项目默认使用本地 Mock 数据，不需要 CloudBase 环境和大模型密钥。首次进入会依次体验 Mock 微信登录、资料完善和 10 道兴趣测试。

## 功能入口

- 首页：快速找搭子、AI 推荐活动、活动列表。
- 发现：支持自然语言 AI 搜索，例如“周六下午找新手打羽毛球”。
- AI：兴趣画像、搭子推荐、AI 活动起草。
- 消息：会话列表、基础文字聊天和 AI 回复建议。
- 我的：兴趣标签、我的活动、兴趣画像和演示数据重置。

## 目录说明

- `pages/`：页面和页面交互。
- `components/`：16 个可复用展示组件。
- `utils/repository.js`：统一数据仓储，是后续替换 CloudBase 的边界。
- `utils/ai.js`：确定性 Mock AI，是后续接入云函数或大模型 API 的边界。
- `utils/match.js`：匹配度计算和推荐解释。
- `tests/`：业务规则测试。

## 本地校验

```bash
npm test
npm run check
```

真实 CloudBase 接入时，保持页面调用方式不变，只需要将 `utils/repository.js` 中的本地存取替换为云数据库/云函数适配器，并将 `utils/ai.js` 的实现迁移到服务端，避免在小程序前端暴露密钥。
